# 🛡️ Secure Coding Review

A cybersecurity project developed as part of my **CodeAlpha Cybersecurity Internship** to demonstrate common web application vulnerabilities and secure coding practices.

## 📌 Project Overview

This project compares a vulnerable Flask web application with a more secure implementation.

The goal is to understand how insecure coding practices can introduce security risks and how developers can apply safer coding techniques.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- Git & GitHub
